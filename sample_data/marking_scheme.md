# University A — MCQ marking scheme

Reviewers must evaluate every question against these criteria:

- Every question must map to a Course Outcome (CO1–CO5); reject questions that map to none.
- Distractors must be plausible and similar in length to the correct answer.
- No question should test more than one concept at a time.
- Prefer scenario/application questions over pure recall.
- Numeric answers must be unambiguous and computable from the stem alone.
